# 私域社群运营台（siyu-private-operation-workbench）

一个面向个人和小团队的**本地私域社群运营工作台**（DSH Desktop 工作台插件）。整页业务界面（`customFrame`），纯前端 + `localStorage` 存储，**数据只保存在本机浏览器里，无服务器、无云端同步**。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 📊 私域概览 | 今日焦点、核心数据卡片（私域总成员 / 活跃成员 / 付费转化率 / 流失预警）、近期排期、各阵地健康度一览 |
| 🏘️ 社群资产管理 | 登记每个社群阵地（平台 / 名称 / 成员数 / 活跃人数 / 运营阶段 / 备注），按平台筛选、增删改 |
| 👥 成员分层运营 | 把重点成员按 KOC核心 / 付费用户 / 活跃粉 / 流失预警 等层级打标签管理，只记值得单独运营的人 |
| 📅 社群运营日历 | 月历视图排期每日话题、每周活动、直播、答疑等，点日期即可添加，带本月排期清单 |
| 📈 私域转化追踪 | 进群 → 活跃 → 咨询 → 付费 的可视化漏斗，自动算每一环转化率，并对比各社群转化潜力 |
| 📝 运营复盘 | 月度数据记录（新增 / 流失 / 活跃 / 新付费）+ 内联 SVG 画的总成员成长曲线 |
| 💬 群话术库 | 按 欢迎语 / 活动通知 / 转化促单 等分类存常用话术，一键复制直接发群 |
| 🎯 进群引流页 | 附带一个可编辑的进群引流落地页（预览 / 编辑内容） |

## 技术栈

- React（宿主注入）
- `localStorage`（数据持久化，key = `wb_scrm_*`）
- DSH Desktop 工作台框架（`customFrame: true`，业务整页）
- 数据仅存本机浏览器，无网络依赖

## 安装

- **市场来源**：提交到工作台市场后，可在 DSH Desktop 的「工作台市场」中搜索并安装本工作台。
- **本地安装**：`pnpm pack` 生成 `.tgz`，用 `install_local_workbench` 安装。

## 开发与构建

工作台源码在仓库根目录。重新生成客户端并打包：

```bash
node scripts/build-client.mjs   # 把 lib/ 里的本地 HTML 源嵌入 client.js
pnpm pack                       # 生成 siyu-private-operation-workbench-<version>.tgz
```

生成的 `.tgz` 用 `install_local_workbench` 安装到本机 Desktop 验证。
